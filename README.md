# Hospital SQL Practice Project

## Overview

This project contains SQL practice based on a hospital database, covering patient records, doctor data, and hospital admissions.

This work focuses on:

* Basic to intermediate SQL queries  
* Data aggregation  
* Table joins  
* Simple data exploration  

---

## Database Structure

The database consists of the following main tables:

* **Patients** → stores patient data  
* **Admissions** → stores hospital visit records  
* **Doctors** → stores doctor data  
* **Province_Names** → stores province mapping  

---

## Features / What’s Inside

This repository includes:

### 1. Database Schema (DDL)

* Table creation  
* Table relationships (foreign keys)  

### 2. Sample Data (DML)

* Dummy dataset for testing  
* Simulated hospital scenarios  

### 3. SQL Queries

Example case studies solved in this project:

* Filtering patients by gender  
* Creating full name using CONCAT  
* Counting patients by birth year  
* Joining tables to get province names  
* Aggregating male vs female patients  
* Unit conversion (height & weight)  
* Doctor admissions per year  
* Insurance cost calculation  
* Filtering by diagnosis and doctor  

---

## Skills Demonstrated

* SQL Fundamentals  
* JOIN operations (INNER JOIN)  
* GROUP BY & aggregation  
* Aggregate Functions (COUNT, SUM)  
* Data filtering (WHERE, LIKE)  
* Conditional logic (CASE)  
* String & date functions  

---

## How to Use

1. Clone this repository  
2. Run the SQL files in MySQL or any compatible DBMS  
3. Execute:

   * Schema (CREATE TABLE)  
   * Data (INSERT)  
   * Practice queries
